# Pão & Gourmet

Cardápio demonstrativo: três páginas e três propostas visuais. Fotos e preços ilustrativos. Recriação independente da versão anterior, não um backup histórico exato.

## Executar

```sh
bun install
bun run dev
```

## Testar

```sh
bun run test
```

React 19, TanStack Start e Tailwind CSS. Nenhum pagamento ou pedido real.
